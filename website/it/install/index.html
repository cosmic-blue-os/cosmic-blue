Installare Celenn OS passo passo

Calcola mezz’ora. Puoi provare Celenn OS prima dalla chiavetta USB: sul computer non cambia nulla finché non avvii l’installazione.

Chiavetta USB da 8 GBverrà cancellata
64 GB di disco128 GB consigliati
4 GB di memoria8 GB consigliati
PC a 64 bitIntel o AMD

  1. Fai un backup dei file

    Copia documenti e foto su un disco esterno o online. Fallo anche se tieni Windows: un errore sul disco capita in fretta.

  2. Scarica la versione giusta

    Una scheda grafica NVIDIA (GeForce GTX 16xx, RTX)? Prendi la versione NVIDIA, altrimenti quella standard. Per saperlo, in Windows: Gestione dispositivi → Schede video.

    Scarica

  3. Prepara la chiavetta

    Installa Fedora Media Writer (Windows o Mac), scegli Seleziona file .iso, poi la chiavetta, poi Scrivi.

  4. Avvia dalla chiavetta

    Con la chiavetta inserita, accendi il computer premendo più volte il tasto della sua marca, poi scegli la chiavetta USB.

    MarcaTasto
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    AltraF12, F11 / Esc

    Non funziona? Da Windows: Impostazioni → Sistema → Ripristino → Avvio avanzato → Riavvia ora, poi Usa un dispositivo.

  5. Prova, poi installa

    Il desktop di Celenn OS parte dalla chiavetta. Controlla Wi-Fi, audio e schermo. Se va tutto bene, apri Install Celenn OS sul desktop.

  6. Scegli dove installare

    Sostituire Windows il più semplice

    Nel programma di installazione scegli il disco e libera spazio eliminando tutto. L’intero disco viene cancellato.

    Accanto a Windows

    Prima, in Windows, apri Gestione disco, clicca col tasto destro sulla partizione di Windows e scegli Riduci volume per liberare almeno 64 GB. Il programma di installazione userà poi da solo quello spazio libero.

    Prima di ridurre, disattiva la crittografia in Windows: Impostazioni → Privacy e sicurezza → Crittografia dispositivo (o BitLocker). Un secondo disco solo per Celenn OS è ancora più semplice.

    Poi Celenn OS parte per impostazione predefinita. Per avviare Windows, usa il tasto del passo 4 e scegli Windows Boot Manager.

  7. Versione NVIDIA: una schermata blu al primo riavvio

    È normale e succede una sola volta, con Secure Boot attivo: permette di caricare il driver NVIDIA. Usa le frecce e Invio. La password è celennos (la tastiera può essere in QWERTY inglese).

    Saltata? Il desktop parte comunque, senza il driver NVIDIA. Apri Strumenti di Celenn OS → Driver NVIDIA, clicca su Consenti e riavvia.

  8. Benvenuti

    Dopo il riavvio, crea il tuo account. Si apre poi il tour, che ti aiuta a sistemare tutto.
