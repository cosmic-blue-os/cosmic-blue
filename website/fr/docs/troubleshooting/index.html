Dépannage

Quelque chose ne va pas ? La plupart des problèmes sur cosmic-blue se rattrapent : la version précédente du système reste installée, et vos réglages COSMIC peuvent revenir aux valeurs par défaut. Les commandes se tapent dans un terminal. Voir aussi la documentation.

L'ordinateur ne démarre plus après une mise à jour

  1. Allumez l'ordinateur et appuyez plusieurs fois sur Échap (ou maintenez Maj) jusqu'à voir le menu de démarrage.
  2. Choisissez la deuxième entrée, marquée ostree:1 : c'est la version d'avant la mise à jour.
  3. Une fois sur le bureau, gardez cette version pour les démarrages suivants :
sudo bootc rollback

Suivez ensuite la section suivante pour que la version cassée ne revienne pas.

Une mise à jour a cassé quelque chose

Revenez à la version d'avant. Elle reste installée jusqu'à la mise à jour suivante, donc cela marche sans réseau :

sudo bootc rollback    # utiliser la version précédente au prochain démarrage
sudo systemctl reboot

Les mises à jour automatiques réinstalleraient la version cassée. Mettez-les en pause, signalez le problème, et réactivez-les une fois la correction publiée :

ujust toggle-updates disable   # mettre en pause les mises à jour automatiques
ujust toggle-updates enable    # les réactiver plus tard

Revenir plus loin en arrière

Chaque construction a sa propre version, comme 44.20261110 : sudo bootc status affiche la vôtre, et la page des versions liste celles de chaque semaine. Vous pouvez en installer une, puis revenir aux mises à jour normales plus tard. Sur l'image NVIDIA, écrivez cosmic-blue-nvidia au lieu de cosmic-blue.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:44.20261110   # rester sur cette version
sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:stable        # revenir aux mises à jour hebdomadaires

Le bureau ne s'ouvre pas

Écran noir, ou retour à l'écran de connexion après avoir tapé votre mot de passe ? Vos réglages COSMIC peuvent en être la cause.

  1. Appuyez sur Ctrl+Alt+F3 pour ouvrir une console texte, et connectez-vous avec votre nom d'utilisateur et votre mot de passe.
  2. Réinitialisez les réglages COSMIC (vos fichiers et applications ne sont pas touchés), puis redémarrez :
ujust reset-cosmic-config
sudo systemctl reboot

Si le problème est apparu après une mise à jour, revenez plutôt à la version précédente depuis la même console.

Apparence et réglages

Vous avez perdu le style cosmic-blue, ou un panneau, le dock ou un raccourci se comporte mal ? Réinitialisez seulement l'apparence, ou tous les réglages COSMIC. Déconnectez-vous puis reconnectez-vous ensuite.

ujust reset-cosmic-theme
Restaurer les couleurs, le thème sombre, les icônes, les polices et le fond d'écran. Le panneau, le dock, le clavier et les raccourcis sont gardés.
ujust reset-cosmic-config
Réinitialiser tous les réglages COSMIC, en gardant la disposition du clavier et le format de l'heure. Les anciens réglages sont déplacés dans un dossier ~/.config/cosmic.backup-, et la commande indique comment les remettre.

Une application ne marche pas

Les applications du COSMIC Store sont des Flatpak. Mettez-les à jour et réparez les fichiers installés d'abord :

flatpak update
sudo flatpak repair

Toujours cassée ? Lancez l'application avec des réglages neufs. Trouvez son identifiant, puis mettez ses données de côté (remettez le dossier pour annuler) :

flatpak list --app
mv ~/.var/app/org.example.App ~/.var/app/org.example.App.old

Une application de FlatPark se comporte mal ? ujust toggle-flatpark off désinstalle ses applications et désactive FlatPark.

Les mises à jour ne s'installent pas

Lancez la mise à jour à la main pour voir l'erreur, et vérifiez que les mises à jour automatiques sont actives :

ujust update
ujust toggle-updates

Disque plein ? Dans Outils cosmic-blue, Entretien, Nettoyer supprime ce qui ne sert plus : runtimes Flatpak, images de conteneurs inutilisées, anciens téléchargements Homebrew. Vos fichiers, vos conteneurs et leurs volumes restent. Dans un terminal : ujust clean-system.

Pilote NVIDIA

Sur l'image NVIDIA avec Secure Boot actif, le pilote ne se charge qu'une fois sa clé enregistrée. Lancez la commande ci-dessous et redémarrez : un écran bleu propose Enroll MOK, avec le mot de passe cosmicblue (tapé sur une disposition QWERTY).

ujust enroll-secure-boot-key

Vous avez installé l'image standard sur un ordinateur avec une carte NVIDIA ? Passez à l'image NVIDIA :

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue-nvidia:stable

Signaler un problème

Lancez la première commande ci-dessous sur l'ordinateur concerné : elle rassemble les informations du système (aucune donnée personnelle) et ouvre un rapport de bug déjà rempli avec elles (en anglais de préférence). Dites ce que vous avez fait et ce qui s'est passé. Si le problème est apparu au démarrage précédent, ajoutez les erreurs qu'il a enregistrées (seconde commande). Les questions vont dans les Discussions.

ujust report-bug
sudo journalctl -b -1 -p err --no-pager
