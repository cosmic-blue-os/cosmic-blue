Installer Celenn OS, pas à pas

Comptez une demi-heure. Vous pouvez d’abord essayer Celenn OS depuis la clé USB : rien ne change sur l’ordinateur tant que vous ne lancez pas l’installation.

Clé USB de 8 Goelle sera effacée
64 Go de disque128 Go conseillés
4 Go de mémoire8 Go conseillés
PC 64 bitsIntel ou AMD

  1. Sauvegardez vos fichiers

    Copiez vos documents et photos sur un disque externe ou en ligne. Faites-le même si vous gardez Windows : une erreur de disque est vite arrivée.

  2. Téléchargez la bonne version

    Une carte graphique NVIDIA (GeForce GTX 16xx, RTX) ? Prenez la version NVIDIA, sinon la version standard. Pour savoir, sous Windows : Gestionnaire de périphériques → Cartes graphiques.

    Télécharger

  3. Créez la clé USB

    Installez Fedora Media Writer (Windows ou Mac), choisissez Sélectionner un fichier .iso, puis votre clé, puis Écrire.

  4. Démarrez sur la clé

    Clé branchée, allumez l’ordinateur en appuyant plusieurs fois sur la touche de votre marque, puis choisissez la clé USB.

    MarqueTouche
    Acer, Dell, LenovoF12
    HPF9 / Échap
    ASUSF8 / Échap
    MSIF11
    AutreF12, F11 / Échap

    Ça ne marche pas ? Depuis Windows : Paramètres → Système → Récupération → Démarrage avancé → Redémarrer maintenant, puis Utiliser un périphérique.

  5. Essayez, puis installez

    Le bureau Celenn OS démarre depuis la clé. Vérifiez le Wi-Fi, le son et l’écran. Quand tout va bien, ouvrez Install Celenn OS sur le bureau.

  6. Choisissez où installer

    Remplacer Windows le plus simple

    Dans l’installateur, choisissez le disque et demandez à libérer de l’espace en supprimant tout. Tout le disque est effacé.

    À côté de Windows

    D’abord, dans Windows, ouvrez Gestion des disques, faites un clic droit sur la partition Windows et Réduire le volume pour libérer au moins 64 Go. L’installateur utilise ensuite cet espace libre tout seul.

    Avant de réduire, coupez le chiffrement dans Windows : Paramètres → Confidentialité et sécurité → Chiffrement de l’appareil (ou BitLocker). Un second disque rien que pour Celenn OS est encore plus simple.

    Celenn OS démarre ensuite par défaut. Pour lancer Windows, utilisez la touche de l’étape 4 et choisissez Windows Boot Manager.

  7. Version NVIDIA : un écran bleu au premier redémarrage

    C’est normal et n’arrive qu’une fois, quand Secure Boot est activé : il autorise le pilote NVIDIA. Utilisez les flèches et Entrée. Le mot de passe est celennos (le clavier peut être en QWERTY).

    Raté ? Le bureau démarre quand même, sans le pilote NVIDIA. Ouvrez Outils Celenn OS → Pilote NVIDIA, cliquez sur Autoriser, puis redémarrez.

  8. Bienvenue

    Après le redémarrage, créez votre compte. La visite guidée s’ouvre ensuite et vous aide à tout régler.
