Documentation

What you need to know to use Celenn OS day to day. Celenn OS is an independent atomic image built on the Universal Blue base: the system is read-only and updated as a whole, and your apps and files live apart from it.

Updates and rollback

The Updates app shows the version you run. If something goes wrong after an update, Go back in Celenn OS Tools returns to the previous version at the next restart, without touching your files, and the version you leave is not installed again. Get new features early, under For experienced users…, brings an update every day instead of one tested update a week.

The system, Flatpak apps, Homebrew packages and the AppImages added with Gear Lever update by themselves in the background. A system update applies on the next boot. To update now, or to turn the automatic updates off:

ujust update           # update everything now
ujust toggle-updates   # turn automatic updates on or off

If an update breaks something, go back to the previous version. It stays installed until the next update, so this works offline:

sudo bootc rollback    # use the previous version on next boot
sudo systemctl reboot
sudo bootc status      # see the current and previous versions

The computer no longer starts, or the broken version keeps coming back? See Troubleshooting.

Installing software

Apps: COSMIC Store

Graphical apps come as Flatpaks from the COSMIC Store, which shows Flathub and the COSMIC apps. They update with the system and do not touch it.

AppImages: Gear Lever

Open a downloaded AppImage: Gear Lever adds it to the app list and keeps it up to date.

Web apps

WhatsApp, Netflix, Gmail or any other site can open in its own window, with its icon in the app list, like an app: Celenn OS Tools, Web apps. They use Firefox, so its protection against ads and tracking and the parental controls apply. Sign in once in each one. Also add to the dock keeps its icon in the dock.

Command line tools: Homebrew

Command line tools install in your home folder with Homebrew:

brew search ripgrep
brew install ripgrep

Packages from other distributions: Distrobox

Need a package that only exists for another distribution? Distrobox runs it in a container that shares your home folder:

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Developer tools

Developer mode adds Docker, Podman Desktop, VS Code and other IDEs, Lima and more. Pick what you want from a menu:

ujust install-dev-tools

Printers, firmware, battery

Printers and scanners

Most network and USB printers work right away, without a driver. To add one by hand, open Print Settings: drivers for HP, Epson, Brother, Canon and others are installed. Document Scanner scans with network and USB scanners.

Other disks

A second internal disk, or Windows' D: drive, can open at every startup: in Celenn OS Tools, Other disks. It is then always at the same place, /mnt/<its name>, in Files and for Steam, which can keep a library there. A disk in Windows format (NTFS) only opens if Windows was fully shut down: turn off Windows' Fast Startup. The disk Windows runs from and encrypted disks are not offered.

Firmware updates

The Firmware app updates the firmware of the computer and its devices (BIOS/UEFI, SSD, dock…), when their maker publishes it on fwupd.org. Or from the terminal:

ujust update-firmware

Laptop battery

A battery that stays plugged in lasts longer when it is not always full. On laptops that allow it, this stops charging at 80%:

ujust toggle-battery-limit

Celenn OS Tools

Celenn OS Tools is a toolbox: each tile opens one tool. Every day: update, install apps, web apps, free up space, protect your files, print, change computers. My computer: what is inside, the battery, other disks, the look, the NVIDIA driver, Microsoft fonts. When something is wrong: go back, repair, get help. A line at the top says when something needs your attention, and For experienced users… gathers the update channel, older versions, firmware and virtual machines. Each tool shows the matching ujust command, and its ? button opens its part of this guide. Changes to the system ask for an administrator's password.

From anywhere, Super + Alt + Space opens the Quick menu: take a screenshot, see the keyboard shortcuts, lock the screen, or type what you want to do to find the right tool. Press the shortcut again, or Escape, to close it.

Parental controls

The Parental controls app creates child accounts and sets for each one a daily screen time (weekdays and weekend), bedtime hours and a family web filter. Only the time in front of the screen counts. The child is warned 10, 5 and 1 minutes before the session closes, and can ask for more time, which a parent gives with their password.

What it cannot stop

The web filter blocks adult content, gambling and malicious sites in every browser of the child's account, and forces safe search. It also refuses the usual ways around it: other DNS servers, encrypted DNS to public resolvers, and VPN connections the child would add. It cannot block everything: an app that hides its traffic as ordinary web browsing, such as Tor Browser or a VPN browser extension, gets around it, and someone with the computer in hand can start another system from a USB stick. Screen time has a limit of the same kind: a child who knows the terminal can make the system believe the screen is locked, which stops the count, but bedtime still closes the session. Keep an eye on the apps a child installs.

ujust commands

ujust runs the shortcuts that come with the system. Type ujust to list them all, or ujust --choose to pick one from a menu. Each install-… command has a matching remove-…. The most useful:

ujust update
Update the system, apps and Homebrew packages now.
ujust toggle-updates
Turn automatic updates on or off.
ujust update-firmware
Install firmware updates (BIOS/UEFI, SSD, dock…).
ujust switch-channel
Switch between the stable images (weekly, the default), testing (daily) and dev (every merged change).
ujust install-dev-tools
Developer tools, picked from a menu: Docker, VS Code, Podman Desktop…
ujust install-cli-tools
Command line tools: bat, eza, fd, ripgrep, zoxide…
ujust install-microsoft-fonts
Microsoft fonts: Arial, Times New Roman, Verdana…
ujust install-gaming
Steam and Heroic (Epic Games, GOG, Amazon).
ujust toggle-flatpark
Turn FlatPark, an extra source of apps, on or off. Off by default: its apps are not reviewed like Flathub's.
ujust toggle-dark-mode
Switch between the dark and light themes.
ujust reset-cosmic-theme
Bring back the Celenn OS look.
ujust reset-cosmic-config
Reset all COSMIC settings (a backup is kept).
ujust toggle-battery-limit
Stop charging the laptop at 80% so the battery lasts longer.
ujust toggle-tpm2
Unlock the encrypted disk with the TPM2 chip, without a password.
ujust enroll-secure-boot-key
NVIDIA with Secure Boot: enroll the driver's key.
ujust report-bug
Open a bug report with your system details filled in.

The look

Celenn OS comes with a blue COSMIC theme, frosted glass panels, Celenn OS wallpapers, icons and cursors. Change anything in Settings. If you want the original look back:

ujust reset-cosmic-theme

To see every keyboard shortcut of the desktop on one page, press Super + F1. Press it again, or Escape, to close it.

Terminal

Each new terminal shows a welcome message with a tip. fastfetch shows the system information. To turn the welcome message off, or back on:

uwelcome toggle

Your data

Updates replace the system only: your home folder, your apps and their settings are kept, and so are your changes to /etc.

Disk encryption

Encryption is chosen in the installer: under Installation Destination, tick Encrypt my data and pick a passphrase. Do it on a laptop, which can be lost or stolen. It cannot be turned on later without reinstalling. Once installed, the TPM2 chip can unlock the disk at startup instead of the passphrase:

ujust toggle-tpm2

Backups

The Backups app (Déjà Dup) is installed: it saves your home folder to an external drive, a network share or a cloud storage, encrypted if you want, and restores single files or everything. For the terminal, restic, borg and rclone are installed too.

Trash

Files that stay in the trash for more than 30 days are deleted on their own. To keep them, turn off Delete files that stayed in the trash for more than 30 days in Celenn OS Tools, under Free up space. This only concerns the trash of your home folder, not that of USB drives.

Coming from another system

Back up your files first (Backups, or a copy to an external drive), install Celenn OS, then copy them back into your home folder. Install your apps again from COSMIC Store; Flatpak apps keep their data in ~/.var/app, which you can copy over from another system that used the same Flatpaks.

Privacy

Celenn OS collects nothing about you. What the system contacts on its own:

  • Updates, once a day: the Celenn OS images on GitHub, Flathub and the COSMIC app repository, and Homebrew if you use it (with Homebrew's usage statistics turned off).
  • Fedora's anonymous weekly count (rpm-ostree-countme): one request a week to Fedora's servers, with the Fedora release and a rough age of the system but no identifier, so that Fedora knows how many systems use it.
  • Firefox: telemetry, studies, sponsored content and ad measurement are off. uBlock Origin blocks ads and trackers, and sites open over HTTPS whenever they can.
  • The Web apps tool: the first time it opens, it fetches the logo of each site it offers from that site, and keeps it on the computer. A site you add yourself is contacted the same way.
  • Child accounts with the web filter on (Parental controls): to block sites, the names of the sites they open are sent to the CleanBrowsing family filter instead of the usual DNS server.
  • Tailscale is installed, for sudo tailscale up: its service runs but does not join any network until you sign in.

To stop the Fedora count, or the Tailscale service if you do not use it:

sudo systemctl mask --now rpm-ostree-countme.timer
sudo systemctl disable --now tailscaled.service

The firewall (firewalld) is on; the Firewall app changes its settings. Flatseal shows and changes what each Flatpak app may access (files, devices, network).

Checking the downloads

The checksum of each live ISO is signed with the project key, cosign.pub. Download the ISO, its .sha256 file and its .sha256.sigstore.json signature into the same folder, then check them with cosign (for the NVIDIA ISO, use the celenn-nvidia-live-amd64 names):

cosign verify-blob --key cosign.pub \
  --bundle celenn-live-amd64.iso.sha256.sigstore.json \
  celenn-live-amd64.iso.sha256
sha256sum -c celenn-live-amd64.iso.sha256

System images are signed too, and installed systems refuse unsigned updates. Each image also carries a signed list of its packages (an SPDX SBOM):

cosign verify --key cosign.pub ghcr.io/celenn-os/celenn:stable
cosign verify-attestation --key cosign.pub --type spdxjson \
  --insecure-ignore-tlog=true ghcr.io/celenn-os/celenn:stable

Getting help

Something not working? The troubleshooting page covers the common problems.

A question, or something unclear? Ask in Discussions.

Found a bug? Run this in a terminal on the computer with the problem: it collects the system details (no personal data) and opens a bug report with them filled in. Then say what you did and what happened.

ujust report-bug
