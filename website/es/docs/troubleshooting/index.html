Solución de problemas

¿Algo ha salido mal? La mayoría de los problemas en Celenn OS se pueden deshacer: la versión anterior del sistema sigue instalada, y tu configuración de COSMIC se puede devolver a los valores predeterminados. Los comandos se escriben en una terminal. Consulta también la documentación.

El equipo no arranca tras una actualización

  1. Enciende el equipo y pulsa Esc varias veces (o mantén pulsada Mayús) hasta que aparezca el menú de arranque.
  2. Elige la segunda entrada, marcada como ostree:1: es la versión que tenías antes de la actualización.
  3. Una vez en el escritorio, conserva esa versión también para los próximos arranques:
sudo bootc rollback

Después sigue la sección siguiente para que la versión rota no vuelva.

Una actualización rompió algo

Vuelve a la versión que tenías antes. Sigue instalada hasta la próxima actualización, así que funciona sin conexión:

sudo bootc rollback    # usar la versión anterior en el próximo arranque
sudo systemctl reboot

Las actualizaciones automáticas volverían a instalar la versión rota. Ponlas en pausa, informa del problema y vuelve a activarlas cuando salga una corrección:

ujust toggle-updates disable   # pausar las actualizaciones automáticas
ujust toggle-updates enable    # reactivarlas más tarde

Volver más atrás

Cada versión tiene su propio número, como 44.20261110: sudo bootc status muestra la tuya, y la página de versiones lista las semanales. Puedes instalar una de ellas y volver más tarde a las actualizaciones normales. En la imagen de NVIDIA, escribe celenn-nvidia en lugar de Celenn OS.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn:44.20261110   # quedarse en esta versión
sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn:stable        # volver a las actualizaciones semanales

El escritorio no se inicia

¿Pantalla negra, o de vuelta a la pantalla de inicio de sesión tras escribir la contraseña? Puede que la causa sea tu configuración de COSMIC.

  1. Pulsa Ctrl+Alt+F3 para abrir una consola de texto, e inicia sesión con tu nombre de usuario y contraseña.
  2. Restablece la configuración de COSMIC (tus archivos y aplicaciones no se tocan) y reinicia:
ujust reset-cosmic-config
sudo systemctl reboot

Si empezó tras una actualización, vuelve a la versión anterior desde la misma consola.

Aspecto y configuración

¿Has perdido el aspecto de Celenn OS, o un panel, el dock o un atajo ya no se comporta bien? Restablece solo la apariencia, o toda la configuración de COSMIC. Cierra la sesión y vuelve a entrar después.

ujust reset-cosmic-theme
Recupera los colores, el tema oscuro, los iconos, las fuentes y el fondo de pantalla. El panel, el dock, el teclado y los atajos se conservan.
ujust reset-cosmic-config
Restablece toda la configuración de COSMIC, pero conserva la distribución del teclado y el formato de la hora. La configuración anterior se mueve a una carpeta ~/.config/cosmic.backup-, y el comando indica cómo recuperarla.

Una aplicación no funciona

Las aplicaciones de COSMIC Store son Flatpak. Primero actualízalas y repara los archivos instalados:

flatpak update
sudo flatpak repair

¿Sigue sin funcionar? Inicia la aplicación con una configuración nueva. Busca su ID y aparta sus datos (devuelve la carpeta a su sitio para deshacerlo):

flatpak list --app
mv ~/.var/app/org.example.App ~/.var/app/org.example.App.old

¿Una aplicación de FlatPark falla? ujust toggle-flatpark off desinstala sus aplicaciones y desactiva FlatPark.

Las actualizaciones no se instalan

Lanza la actualización a mano para ver el error, y comprueba que las actualizaciones automáticas estén activadas:

ujust update
ujust toggle-updates

¿Disco lleno? En Herramientas de Celenn OS, Liberar espacio, Limpiar elimina lo que ya nada usa: runtimes de Flatpak, imágenes de contenedor sin usar, descargas antiguas de Homebrew. Tus archivos, tus contenedores y sus volúmenes se quedan. En una terminal: ujust clean-system.

Controlador de NVIDIA

En la imagen de NVIDIA con Secure Boot activado, el controlador solo se carga cuando su clave está registrada. Ejecuta el comando de abajo y reinicia: una pantalla azul pide Enroll MOK, con la contraseña celennos (escrita en distribución QWERTY).

ujust enroll-secure-boot-key

¿Instalaste la imagen estándar en un equipo con tarjeta NVIDIA? Cambia a la imagen de NVIDIA:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/celenn-os/celenn-nvidia:stable

Informar de un problema

Ejecuta el primer comando de abajo en el equipo con el problema: recopila los datos del sistema (ningún dato personal) y abre un informe de error con ellos ya rellenados. Cuenta qué hiciste y qué pasó. Si el problema apareció durante el arranque anterior, añade los errores que registró (segundo comando). Las preguntas van a Discussions.

ujust report-bug
sudo journalctl -b -1 -p err --no-pager
