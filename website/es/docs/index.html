Documentación

Lo que necesitas saber para usar Celenn OS en el día a día. Celenn OS es una imagen atómica independiente construida sobre la base de Universal Blue: el sistema es de solo lectura y se actualiza como un todo, y tus aplicaciones y archivos viven aparte.

Actualizaciones y vuelta atrás

La aplicación Actualizaciones muestra la versión en uso. Si algo va mal tras una actualización, Volver atrás, en Herramientas de Celenn OS, vuelve a la versión anterior en el próximo reinicio, sin tocar tus archivos, y la versión que deja no se vuelve a instalar. Recibir las novedades antes, en Para usuarios avanzados…, trae una actualización cada día en lugar de una actualización probada por semana.

El sistema, las aplicaciones Flatpak, los paquetes de Homebrew y los AppImage añadidos con Gear Lever se actualizan solos en segundo plano. Una actualización del sistema se aplica en el siguiente arranque. Para actualizar ahora, o para desactivar las actualizaciones automáticas:

ujust update           # actualizar todo ahora
ujust toggle-updates   # activar o desactivar las actualizaciones automáticas

Si una actualización rompe algo, vuelve a la versión anterior. Sigue instalada hasta la próxima actualización, así que funciona sin conexión:

sudo bootc rollback    # usar la versión anterior en el próximo arranque
sudo systemctl reboot
sudo bootc status      # ver la versión actual y la anterior

¿El equipo ya no arranca, o la versión rota vuelve una y otra vez? Consulta Solución de problemas.

Instalar programas

Aplicaciones: COSMIC Store

Las aplicaciones gráficas llegan como Flatpak desde COSMIC Store, que muestra Flathub y las aplicaciones de COSMIC. Se actualizan con el sistema y no lo modifican.

AppImage: Gear Lever

Abre un AppImage descargado: Gear Lever lo añade a la lista de aplicaciones y lo mantiene al día.

Aplicaciones web

WhatsApp, Netflix, Gmail o cualquier otro sitio pueden abrirse en su propia ventana, con su icono en la lista de aplicaciones, como una aplicación: Herramientas de Celenn OS, Aplicaciones web. Usan Firefox, así que su protección contra anuncios y rastreo y el control parental se aplican. Inicia sesión una vez en cada una. Añadir también al dock mantiene su icono en el dock.

Herramientas de línea de comandos: Homebrew

Las herramientas de línea de comandos se instalan en tu carpeta personal con Homebrew:

brew search ripgrep
brew install ripgrep

Paquetes de otras distribuciones: Distrobox

¿Necesitas un paquete que solo existe para otra distribución? Distrobox lo ejecuta en un contenedor que comparte tu carpeta personal:

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Herramientas de desarrollo

El modo desarrollador añade Docker, Podman Desktop, VS Code y otros IDE, Lima y más. Elige lo que quieras en un menú:

ujust install-dev-tools

Impresoras, firmware, batería

Impresoras y escáneres

La mayoría de las impresoras de red y USB funcionan al instante, sin controlador. Para añadir una a mano, abre Configuración de impresión: hay controladores instalados para HP, Epson, Brother, Canon y otras. Escáner de documentos escanea con escáneres de red y USB.

Otros discos

Un segundo disco interno, o la unidad D: de Windows, puede abrirse en cada inicio: en las Herramientas de Celenn OS, Otros discos. Entonces está siempre en el mismo lugar, /mnt/<su nombre>, en Archivos y para Steam, que puede guardar allí una biblioteca. Un disco en formato Windows (NTFS) solo se abre si Windows se apagó por completo: desactive el inicio rápido de Windows. El disco donde funciona Windows y los discos cifrados no se ofrecen.

Actualizaciones de firmware

La aplicación Firmware actualiza el firmware del equipo y de sus dispositivos (BIOS/UEFI, SSD, dock…), cuando el fabricante lo publica en fwupd.org. O desde la terminal:

ujust update-firmware

Batería del portátil

Una batería que siempre está enchufada dura más si no está siempre llena. En los portátiles que lo permiten, esto detiene la carga al 80 %:

ujust toggle-battery-limit

Herramientas de Celenn OS

Herramientas de Celenn OS es una caja de herramientas: cada mosaico abre una herramienta. Día a día: actualizar, instalar aplicaciones, aplicaciones web, liberar espacio, proteger tus archivos, imprimir, cambiar de ordenador. Mi ordenador: qué hay dentro, la batería, otros discos, el aspecto, el controlador NVIDIA, las fuentes de Microsoft. Cuando algo va mal: volver atrás, reparar, obtener ayuda. Una línea arriba indica lo que necesita tu atención, y Para usuarios avanzados… reúne el canal de actualizaciones, las versiones anteriores, el firmware y las máquinas virtuales. Cada herramienta muestra el comando ujust correspondiente, y su botón ? abre su parte de esta guía. Los cambios del sistema piden la contraseña de un administrador.

Desde cualquier lugar, Super + Alt + Espacio abre el Menú rápido: hacer una captura de pantalla, ver los atajos de teclado, bloquear la pantalla o escribir lo que quieres hacer para encontrar la herramienta adecuada. Vuelve a pulsar el atajo, o pulsa Esc, para cerrarlo.

Control parental

La app Control parental crea cuentas infantiles y fija para cada una un tiempo de pantalla diario (entre semana y fin de semana), horas de dormir y un filtro web familiar. Solo cuenta el tiempo frente a la pantalla. El niño o la niña recibe un aviso 10, 5 y 1 minuto antes de que se cierre la sesión, y puede pedir más tiempo, que un padre o una madre concede con su contraseña.

Lo que no puede impedir

El filtro web bloquea contenido para adultos, apuestas y sitios maliciosos en todos los navegadores de la cuenta infantil, e impone la búsqueda segura. También rechaza los rodeos habituales: otros servidores DNS, DNS cifrado hacia resolvedores públicos y conexiones VPN que el niño o la niña añadiría. No puede bloquearlo todo: una app que hace pasar su tráfico por navegación web normal, como Tor Browser o una extensión VPN del navegador, lo esquiva, y quien tiene el ordenador en las manos puede arrancar otro sistema desde una memoria USB. Vigile las apps que instala un niño o una niña.

Comandos ujust

ujust ejecuta los atajos que trae el sistema. Escribe ujust para verlos todos, o ujust --choose para elegir uno en un menú. Cada comando install-… tiene su remove-…. Los más útiles:

ujust update
Actualizar ahora el sistema, las aplicaciones y los paquetes de Homebrew.
ujust toggle-updates
Activar o desactivar las actualizaciones automáticas.
ujust update-firmware
Instalar actualizaciones de firmware (BIOS/UEFI, SSD, dock…).
ujust switch-channel
Cambiar entre las imágenes stable (semanal, la predeterminada), testing (diaria) y dev (cada cambio fusionado).
ujust install-dev-tools
Herramientas de desarrollo, elegidas en un menú: Docker, VS Code, Podman Desktop…
ujust install-cli-tools
Herramientas de línea de comandos: bat, eza, fd, ripgrep, zoxide…
ujust install-microsoft-fonts
Fuentes de Microsoft: Arial, Times New Roman, Verdana…
ujust install-gaming
Steam y Heroic (Epic Games, GOG, Amazon).
ujust toggle-flatpark
Activar o desactivar FlatPark, una fuente extra de aplicaciones. Desactivado por defecto: sus aplicaciones no se revisan como las de Flathub.
ujust toggle-dark-mode
Cambiar entre el tema oscuro y el claro.
ujust reset-cosmic-theme
Recuperar el aspecto de Celenn OS.
ujust reset-cosmic-config
Restablecer toda la configuración de COSMIC (se guarda una copia).
ujust toggle-battery-limit
Detener la carga del portátil al 80 % para que la batería dure más.
ujust toggle-tpm2
Desbloquear el disco cifrado con el chip TPM2, sin contraseña.
ujust enroll-secure-boot-key
NVIDIA con Secure Boot: registrar la clave del controlador.
ujust report-bug
Abrir un informe de error con los datos de tu sistema ya rellenados.

El aspecto

Celenn OS trae un tema azul de COSMIC, paneles de vidrio esmerilado y fondos de pantalla, iconos y cursores propios. Cámbialo todo en Configuración. Si quieres recuperar el aspecto original:

ujust reset-cosmic-theme

Para ver todos los atajos de teclado del escritorio en una sola página, pulsa Super + F1. Vuelve a pulsarlo, o pulsa Esc, para cerrarla.

Terminal

Cada nueva terminal muestra un mensaje de bienvenida con un consejo. fastfetch muestra la información del sistema. Para desactivar el mensaje de bienvenida, o volver a activarlo:

uwelcome toggle

Tus datos

Las actualizaciones solo sustituyen el sistema: tu carpeta personal, tus aplicaciones y su configuración se conservan, igual que tus cambios en /etc.

Cifrado del disco

El cifrado se elige en el instalador: en Installation Destination, marca Encrypt my data y elige una frase de contraseña. Hazlo en un portátil, que se puede perder o te pueden robar. No se puede activar más tarde sin reinstalar. Una vez instalado, el chip TPM2 puede desbloquear el disco al arrancar en lugar de la frase de contraseña:

ujust toggle-tpm2

Copias de seguridad

La aplicación Copias de seguridad (Déjà Dup) está instalada: guarda tu carpeta personal en un disco externo, una carpeta compartida en red o un almacenamiento en la nube, cifrada si quieres, y restaura archivos sueltos o todo. Para la terminal, también están instalados restic, borg y rclone.

Papelera

Los archivos que llevan más de 30 días en la papelera se eliminan solos. Para conservarlos, desactiva Eliminar los archivos que llevan más de 30 días en la papelera en Herramientas de Celenn OS, en Liberar espacio. Solo afecta a la papelera de tu carpeta personal, no a la de las memorias USB.

Si vienes de otro sistema

Primero haz una copia de tus archivos (con Copias de seguridad, o copiándolos a un disco externo), instala Celenn OS y luego cópialos de vuelta a tu carpeta personal. Vuelve a instalar tus aplicaciones desde COSMIC Store; las aplicaciones Flatpak guardan sus datos en ~/.var/app, que puedes copiar desde otro sistema que usara los mismos Flatpak.

Privacidad

Celenn OS no recopila nada sobre ti. Lo que el sistema contacta por su cuenta:

  • Actualizaciones, una vez al día: las imágenes de Celenn OS en GitHub, Flathub y el repositorio de aplicaciones de COSMIC, y Homebrew si lo usas (con sus estadísticas de uso desactivadas).
  • El recuento semanal anónimo de Fedora (rpm-ostree-countme): una petición por semana a los servidores de Fedora, con la versión de Fedora y la antigüedad aproximada del sistema pero sin ningún identificador, para que Fedora sepa cuántos sistemas la usan.
  • Firefox: la telemetría, los estudios, el contenido patrocinado y la medición publicitaria están desactivados. uBlock Origin bloquea anuncios y rastreadores, y los sitios se abren por HTTPS siempre que es posible.
  • La herramienta Aplicaciones web: la primera vez que se abre, descarga el logotipo de cada sitio que ofrece desde ese mismo sitio y lo guarda en el ordenador. Un sitio que añadas tú se contacta de la misma forma.
  • Cuentas infantiles con el filtro web activado (Control parental): para bloquear sitios, los nombres de los sitios que abren se envían al filtro familiar de CleanBrowsing en lugar del servidor DNS habitual.
  • Tailscale está instalado, para sudo tailscale up: su servicio se ejecuta pero no se une a ninguna red hasta que inicias sesión.

Para detener el recuento de Fedora, o el servicio de Tailscale si no lo usas:

sudo systemctl mask --now rpm-ostree-countme.timer
sudo systemctl disable --now tailscaled.service

El cortafuegos (firewalld) está activado; la aplicación Cortafuegos cambia su configuración. Flatseal muestra y cambia a qué puede acceder cada aplicación Flatpak (archivos, dispositivos, red).

Comprobar las descargas

La suma de comprobación de cada ISO live está firmada con la clave del proyecto, cosign.pub. Descarga la ISO, su archivo .sha256 y su firma .sha256.sigstore.json en la misma carpeta y compruébalos con cosign (para la ISO de NVIDIA, usa los nombres celenn-nvidia-live-amd64):

cosign verify-blob --key cosign.pub \
  --bundle celenn-live-amd64.iso.sha256.sigstore.json \
  celenn-live-amd64.iso.sha256
sha256sum -c celenn-live-amd64.iso.sha256

Las imágenes del sistema también están firmadas, y los sistemas instalados rechazan las actualizaciones sin firmar. Cada imagen incluye además una lista firmada de sus paquetes (un SBOM SPDX):

cosign verify --key cosign.pub ghcr.io/celenn-os/celenn:stable
cosign verify-attestation --key cosign.pub --type spdxjson \
  --insecure-ignore-tlog=true ghcr.io/celenn-os/celenn:stable

Obtener ayuda

¿Algo no funciona? La página de solución de problemas cubre los problemas habituales.

¿Una pregunta, o algo que no queda claro? Pregunta en Discussions.

¿Has encontrado un error? Ejecuta esto en una terminal del equipo con el problema: recopila los datos del sistema (ningún dato personal) y abre un informe de error con ellos ya rellenados. Después cuenta qué hiciste y qué pasó.

ujust report-bug
