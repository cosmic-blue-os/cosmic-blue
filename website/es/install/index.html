Instalar Celenn OS paso a paso

Calcula media hora. Puedes probar Celenn OS primero desde la memoria USB: nada cambia en el ordenador hasta que empieces la instalación.

Memoria USB de 8 GBse borrará
64 GB de disco128 GB recomendados
4 GB de memoria8 GB recomendados
PC de 64 bitsIntel o AMD

  1. Haz una copia de tus archivos

    Copia tus documentos y fotos en un disco externo o en línea. Hazlo aunque conserves Windows: un error de disco ocurre rápido.

  2. Descarga la versión correcta

    ¿Una tarjeta gráfica NVIDIA (GeForce GTX 16xx, RTX)? Elige la versión NVIDIA; si no, la estándar. Para saberlo, en Windows: Administrador de dispositivos → Adaptadores de pantalla.

    Descargar

  3. Prepara la memoria USB

    Instala Fedora Media Writer (Windows o Mac), elige Seleccionar archivo .iso, luego tu memoria y luego Escribir.

  4. Arranca desde la memoria

    Con la memoria conectada, enciende el ordenador pulsando varias veces la tecla de su marca y elige la memoria USB.

    MarcaTecla
    Acer, Dell, LenovoF12
    HPF9 / Esc
    ASUSF8 / Esc
    MSIF11
    OtraF12, F11 / Esc

    ¿No funciona? Desde Windows: Configuración → Sistema → Recuperación → Inicio avanzado → Reiniciar ahora y luego Usar un dispositivo.

  5. Pruébalo y luego instálalo

    El escritorio de Celenn OS arranca desde la memoria. Comprueba el Wi-Fi, el sonido y la pantalla. Si todo va bien, abre Install Celenn OS en el escritorio.

  6. Elige dónde instalar

    Reemplazar Windows lo más sencillo

    En el instalador, elige el disco y libera espacio borrándolo todo. Se borra todo el disco.

    Junto a Windows

    Primero, en Windows, abre Administración de discos, haz clic derecho en la partición de Windows y elige Reducir volumen para liberar al menos 64 GB. El instalador usará ese espacio libre por sí solo.

    Antes de reducir, desactiva el cifrado en Windows: Configuración → Privacidad y seguridad → Cifrado de dispositivo (o BitLocker). Un segundo disco solo para Celenn OS es aún más sencillo.

    Después, Celenn OS arranca por defecto. Para iniciar Windows, usa la tecla del paso 4 y elige Windows Boot Manager.

  7. Versión NVIDIA: una pantalla azul en el primer reinicio

    Es normal y solo pasa una vez, con Secure Boot activado: permite cargar el controlador de NVIDIA. Usa las flechas y Intro. La contraseña es celennos (el teclado puede estar en QWERTY inglés).

    ¿Se te pasó? El escritorio arranca igual, sin el controlador de NVIDIA. Abre Herramientas de Celenn OS → Controlador NVIDIA, pulsa Permitir y reinicia.

  8. Bienvenida

    Tras el reinicio, crea tu cuenta. Después se abre el recorrido, que te ayuda a configurarlo todo.
