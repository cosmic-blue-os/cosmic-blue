Solução de problemas

Algo deu errado? A maioria dos problemas no cosmic-blue pode ser desfeita: a versão anterior do sistema continua instalada, e suas configurações do COSMIC podem voltar ao padrão. Os comandos são digitados em um terminal. Veja também a documentação.

O computador não inicia depois de uma atualização

  1. Ligue o computador e aperte Esc algumas vezes (ou segure Shift) até o menu de inicialização aparecer.
  2. Escolha a segunda entrada, marcada ostree:1: é a versão que você tinha antes da atualização.
  3. Já no desktop, mantenha essa versão também para as próximas inicializações:
sudo bootc rollback

Depois siga a próxima seção para que a versão com problema não volte.

Uma atualização quebrou algo

Volte para a versão que você tinha antes. Ela continua instalada até a próxima atualização, então funciona sem internet:

sudo bootc rollback    # usar a versão anterior na próxima inicialização
sudo systemctl reboot

As atualizações automáticas instalariam de novo a versão com problema. Pause-as, relate o problema e ligue-as de novo quando sair uma correção:

ujust toggle-updates disable   # pausar as atualizações automáticas
ujust toggle-updates enable    # ligá-las de novo depois

Voltar mais

Cada build tem sua própria versão, como 44.20261110: sudo bootc status mostra a sua, e a página de versões lista as semanais. Você pode instalar uma delas e voltar às atualizações normais depois. Na imagem NVIDIA, escreva cosmic-blue-nvidia no lugar de cosmic-blue.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:44.20261110   # ficar nesta versão
sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:stable        # voltar às atualizações semanais

O desktop não inicia

Tela preta, ou de volta à tela de login depois de digitar a senha? Suas configurações do COSMIC podem ser a causa.

  1. Aperte Ctrl+Alt+F3 para abrir um console de texto, e entre com seu nome de usuário e senha.
  2. Redefina as configurações do COSMIC (seus arquivos e aplicativos não são afetados) e reinicie:
ujust reset-cosmic-config
sudo systemctl reboot

Se começou depois de uma atualização, volte para a versão anterior pelo mesmo console.

Aparência e configurações

Perdeu a aparência do cosmic-blue, ou um painel, o dock ou um atalho parou de funcionar direito? Redefina só a aparência, ou todas as configurações do COSMIC. Saia da sessão e entre de novo depois.

ujust reset-cosmic-theme
Restaura as cores, o tema escuro, os ícones, as fontes e o papel de parede. O painel, o dock, o teclado e os atalhos são mantidos.
ujust reset-cosmic-config
Redefine todas as configurações do COSMIC, mas mantém o layout do teclado e o formato do relógio. As configurações antigas vão para uma pasta ~/.config/cosmic.backup-, e o comando mostra como trazê-las de volta.

Um aplicativo não funciona

Os aplicativos da COSMIC Store são Flatpaks. Primeiro atualize-os e repare os arquivos instalados:

flatpak update
sudo flatpak repair

Ainda com problema? Inicie o aplicativo com configurações novas. Encontre o ID dele e mova os dados para o lado (coloque a pasta de volta para desfazer):

flatpak list --app
mv ~/.var/app/org.example.App ~/.var/app/org.example.App.old

Um aplicativo do FlatPark está com problema? ujust toggle-flatpark off desinstala os aplicativos dele e desliga o FlatPark.

As atualizações não instalam

Rode a atualização manualmente para ver o erro, e confira se as atualizações automáticas estão ligadas:

ujust update
ujust toggle-updates

Disco cheio? Em Ferramentas do cosmic-blue, Manutenção, Limpar remove o que nada mais usa: runtimes do Flatpak, imagens de contêiner sem uso, downloads antigos do Homebrew. Seus arquivos, contêineres e seus volumes ficam. No terminal: ujust clean-system.

Driver da NVIDIA

Na imagem NVIDIA com o Secure Boot ativado, o driver só carrega depois que a chave dele é registrada. Rode o comando abaixo e reinicie: uma tela azul pede Enroll MOK, com a senha cosmicblue (digitada em layout QWERTY).

ujust enroll-secure-boot-key

Instalou a imagem padrão em um computador com placa NVIDIA? Mude para a imagem NVIDIA:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue-nvidia:stable

Relatar um problema

Rode o primeiro comando abaixo no computador com o problema: ele coleta os dados do sistema (nenhum dado pessoal) e abre um relatório de bug com eles já preenchidos. Conte o que você fez e o que aconteceu. Se o problema apareceu na inicialização anterior, acrescente os erros registrados (segundo comando). Dúvidas vão para as Discussions.

ujust report-bug
sudo journalctl -b -1 -p err --no-pager
