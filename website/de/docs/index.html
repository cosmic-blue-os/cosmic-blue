Dokumentation

Was Sie für den Alltag mit Celenn OS wissen müssen. Celenn OS ist ein unabhängiges atomares Image auf der Basis von Universal Blue: Das System ist schreibgeschützt und wird als Ganzes aktualisiert, Ihre Apps und Dateien liegen getrennt davon.

Updates und Zurücksetzen

Die App Updates zeigt die laufende Version. Geht nach einem Update etwas schief, wechselt Zurückgehen in Celenn OS Werkzeuge beim nächsten Neustart zur vorherigen Version, ohne Ihre Dateien anzutasten, und die verlassene Version wird nicht wieder installiert. Neuerungen früher erhalten unter Für Erfahrene… bringt jeden Tag ein Update statt eines getesteten Updates pro Woche.

Das System, Flatpak-Apps, Homebrew-Pakete und die mit Gear Lever hinzugefügten AppImages aktualisieren sich selbst im Hintergrund. Ein Systemupdate wird beim nächsten Start aktiv. Um jetzt zu aktualisieren oder die automatischen Updates abzuschalten:

ujust update           # jetzt alles aktualisieren
ujust toggle-updates   # automatische Updates ein- oder ausschalten

Wenn ein Update etwas kaputt macht, kehren Sie zur vorherigen Version zurück. Sie bleibt bis zum nächsten Update installiert, das funktioniert also auch offline:

sudo bootc rollback    # beim nächsten Start die vorherige Version nutzen
sudo systemctl reboot
sudo bootc status      # aktuelle und vorherige Version anzeigen

Der Computer startet nicht mehr, oder die kaputte Version kommt immer wieder? Siehe Fehlerbehebung.

Software installieren

Apps: COSMIC Store

Grafische Apps kommen als Flatpaks aus dem COSMIC Store, der Flathub und die COSMIC-Apps anzeigt. Sie werden mit dem System aktualisiert und verändern es nicht.

AppImages: Gear Lever

Öffnen Sie ein heruntergeladenes AppImage: Gear Lever fügt es zur App-Liste hinzu und hält es aktuell.

Web-Apps

WhatsApp, Netflix, Gmail oder jede andere Seite kann sich in einem eigenen Fenster öffnen, mit ihrem Symbol in der App-Liste, wie eine App: Celenn OS Werkzeuge, Web-Apps. Sie nutzen Firefox, daher gelten sein Schutz vor Werbung und Tracking und die Kindersicherung. Melden Sie sich in jeder einmal an. Auch zum Dock hinzufügen behält ihr Symbol im Dock.

Kommandozeilen-Tools: Homebrew

Kommandozeilen-Tools werden mit Homebrew in Ihrem persönlichen Ordner installiert:

brew search ripgrep
brew install ripgrep

Pakete anderer Distributionen: Distrobox

Sie brauchen ein Paket, das es nur für eine andere Distribution gibt? Distrobox führt es in einem Container aus, der Ihren persönlichen Ordner mitbenutzt:

distrobox create --name arch --image archlinux:latest
distrobox enter arch

Entwicklerwerkzeuge

Der Entwicklermodus bringt Docker, Podman Desktop, VS Code und weitere IDEs, Lima und mehr. Wählen Sie in einem Menü aus, was Sie möchten:

ujust install-dev-tools

Drucker, Firmware, Akku

Drucker und Scanner

Die meisten Netzwerk- und USB-Drucker funktionieren sofort, ohne Treiber. Um einen von Hand hinzuzufügen, öffnen Sie Druckeinstellungen: Treiber für HP, Epson, Brother, Canon und andere sind installiert. Dokumentenscanner scannt mit Netzwerk- und USB-Scannern.

Weitere Laufwerke

Ein zweites internes Laufwerk oder das Laufwerk D: von Windows kann bei jedem Start geöffnet werden: in Celenn OS Werkzeuge unter Weitere Laufwerke. Es liegt dann immer am selben Ort, /mnt/<sein Name>, in Dateien und für Steam, das dort eine Bibliothek anlegen kann. Ein Laufwerk im Windows-Format (NTFS) wird nur geöffnet, wenn Windows vollständig heruntergefahren wurde: Schalten Sie den Schnellstart von Windows aus. Das Laufwerk, auf dem Windows läuft, und verschlüsselte Laufwerke werden nicht angeboten.

Firmware-Updates

Die App Firmware aktualisiert die Firmware des Computers und seiner Geräte (BIOS/UEFI, SSD, Dock…), wenn der Hersteller sie auf fwupd.org veröffentlicht. Oder im Terminal:

ujust update-firmware

Laptop-Akku

Ein Akku, der ständig am Netz hängt, hält länger, wenn er nicht immer voll ist. Auf Laptops, die das erlauben, stoppt dies das Laden bei 80 %:

ujust toggle-battery-limit

Celenn OS Werkzeuge

Celenn OS Werkzeuge ist ein Werkzeugkasten: Jede Kachel öffnet ein Werkzeug. Im Alltag: aktualisieren, Apps installieren, Web-Apps, Speicherplatz freigeben, Dateien schützen, drucken, Computer wechseln. Mein Computer: was drinsteckt, der Akku, weitere Laufwerke, das Aussehen, der NVIDIA-Treiber, Microsoft-Schriften. Wenn etwas nicht stimmt: zurückgehen, reparieren, Hilfe erhalten. Eine Zeile oben zeigt, was Ihre Aufmerksamkeit braucht, und Für Erfahrene… bündelt den Update-Kanal, ältere Versionen, Firmware und virtuelle Maschinen. Jedes Werkzeug zeigt den passenden ujust-Befehl, und sein Knopf ? öffnet seinen Teil dieser Anleitung. Änderungen am System verlangen das Passwort eines Administrators.

Von überall öffnet Super + Alt + Leertaste das Schnellmenü: ein Bildschirmfoto aufnehmen, die Tastenkürzel ansehen, den Bildschirm sperren oder eingeben, was Sie tun möchten, um das passende Werkzeug zu finden. Drücken Sie das Tastenkürzel erneut oder Esc, um es zu schließen.

Jugendschutz

Die App Jugendschutz legt Kinderkonten an und stellt für jedes eine tägliche Bildschirmzeit (Wochentage und Wochenende), Schlafenszeiten und einen Familien-Webfilter ein. Nur die Zeit vor dem Bildschirm zählt. Das Kind wird 10, 5 und 1 Minute vor dem Ende der Sitzung gewarnt und kann um mehr Zeit bitten, die ein Elternteil mit seinem Passwort gewährt.

Was er nicht verhindern kann

Der Webfilter sperrt Inhalte für Erwachsene, Glücksspiel und schädliche Seiten in jedem Browser des Kinderkontos und erzwingt die sichere Suche. Er verweigert auch die üblichen Umwege: andere DNS-Server, verschlüsseltes DNS zu öffentlichen Resolvern und VPN-Verbindungen, die das Kind hinzufügen würde. Alles sperren kann er nicht: Eine App, die ihren Verkehr wie normales Surfen aussehen lässt, etwa der Tor Browser oder eine VPN-Browsererweiterung, kommt daran vorbei, und wer den Computer in der Hand hat, kann ein anderes System von einem USB-Stick starten. Die Bildschirmzeit hat eine Grenze derselben Art: Ein Kind, das sich mit dem Terminal auskennt, kann dem System vorgaukeln, dass der Bildschirm gesperrt ist, und so die Zählung anhalten. Die Schlafenszeit beendet die Sitzung trotzdem. Behalten Sie die Apps im Blick, die ein Kind installiert.

ujust-Befehle

ujust führt die Kurzbefehle aus, die das System mitbringt. Geben Sie ujust ein, um alle aufzulisten, oder ujust --choose, um einen aus einem Menü zu wählen. Zu jedem install-…-Befehl gibt es ein passendes remove-…. Die nützlichsten:

ujust update
System, Apps und Homebrew-Pakete jetzt aktualisieren.
ujust toggle-updates
Automatische Updates ein- oder ausschalten.
ujust update-firmware
Firmware-Updates installieren (BIOS/UEFI, SSD, Dock…).
ujust switch-channel
Zwischen den Images stable (wöchentlich, Standard), testing (täglich) und dev (jede übernommene Änderung) wechseln.
ujust install-dev-tools
Entwicklerwerkzeuge, aus einem Menü gewählt: Docker, VS Code, Podman Desktop…
ujust install-cli-tools
Kommandozeilen-Tools: bat, eza, fd, ripgrep, zoxide…
ujust install-microsoft-fonts
Microsoft-Schriften: Arial, Times New Roman, Verdana…
ujust install-gaming
Steam und Heroic (Epic Games, GOG, Amazon).
ujust toggle-flatpark
FlatPark, eine zusätzliche App-Quelle, ein- oder ausschalten. Standardmäßig aus: Seine Apps werden nicht wie die von Flathub geprüft.
ujust toggle-dark-mode
Zwischen dunklem und hellem Theme wechseln.
ujust reset-cosmic-theme
Das Aussehen von Celenn OS wiederherstellen.
ujust reset-cosmic-config
Alle COSMIC-Einstellungen zurücksetzen (eine Sicherung wird behalten).
ujust toggle-battery-limit
Das Laden des Laptops bei 80 % stoppen, damit der Akku länger hält.
ujust toggle-tpm2
Die verschlüsselte Festplatte mit dem TPM2-Chip entsperren, ohne Passwort.
ujust enroll-secure-boot-key
NVIDIA mit Secure Boot: den Schlüssel des Treibers registrieren.
ujust report-bug
Einen Fehlerbericht öffnen, in dem Ihre Systemdaten schon eingetragen sind.

Das Aussehen

Celenn OS bringt ein blaues COSMIC-Theme, Milchglas-Leisten sowie eigene Hintergrundbilder, Icons und Cursor mit. Ändern Sie alles in den Einstellungen. Wenn Sie das ursprüngliche Aussehen zurückhaben möchten:

ujust reset-cosmic-theme

Alle Tastenkürzel des Desktops auf einer Seite sehen Sie mit Super + F1. Drücken Sie die Tasten erneut oder Esc, um sie zu schließen.

Terminal

Jedes neue Terminal zeigt eine Willkommensnachricht mit einem Tipp. fastfetch zeigt die Systeminformationen. Um die Willkommensnachricht aus- oder wieder einzuschalten:

uwelcome toggle

Ihre Daten

Updates ersetzen nur das System: Ihr persönlicher Ordner, Ihre Apps und deren Einstellungen bleiben erhalten, ebenso Ihre Änderungen an /etc.

Festplattenverschlüsselung

Die Verschlüsselung wird im Installationsprogramm gewählt: Unter Installation Destination setzen Sie das Häkchen bei Encrypt my data und wählen eine Passphrase. Tun Sie das auf einem Laptop, der verloren gehen oder gestohlen werden kann. Später lässt sie sich nur durch eine Neuinstallation einschalten. Nach der Installation kann der TPM2-Chip die Festplatte beim Start statt der Passphrase entsperren:

ujust toggle-tpm2

Datensicherung

Die App Datensicherungen (Déjà Dup) ist installiert: Sie sichert Ihren persönlichen Ordner auf ein externes Laufwerk, eine Netzwerkfreigabe oder einen Cloud-Speicher, auf Wunsch verschlüsselt, und stellt einzelne Dateien oder alles wieder her. Für das Terminal sind auch restic, borg und rclone installiert.

Papierkorb

Dateien, die länger als 30 Tage im Papierkorb liegen, werden von selbst gelöscht. Um sie zu behalten, schalten Sie in Celenn OS Werkzeuge unter Speicherplatz freigeben die Option Dateien löschen, die länger als 30 Tage im Papierkorb liegen aus. Das betrifft nur den Papierkorb Ihres persönlichen Ordners, nicht den von USB-Sticks.

Umstieg von einem anderen System

Sichern Sie zuerst Ihre Dateien (mit Datensicherungen oder als Kopie auf ein externes Laufwerk), installieren Sie Celenn OS und kopieren Sie sie dann zurück in Ihren persönlichen Ordner. Installieren Sie Ihre Apps erneut aus dem COSMIC Store; Flatpak-Apps speichern ihre Daten in ~/.var/app, das Sie von einem anderen System mit denselben Flatpaks übernehmen können.

Datenschutz

Celenn OS sammelt nichts über Sie. Was das System von sich aus kontaktiert:

  • Updates, einmal am Tag: die Celenn-OS-Images auf GitHub, Flathub und das COSMIC-App-Repository, und Homebrew, wenn Sie es nutzen (mit abgeschalteten Nutzungsstatistiken von Homebrew).
  • Fedoras anonyme wöchentliche Zählung (rpm-ostree-countme): eine Anfrage pro Woche an Fedoras Server, mit der Fedora-Version und dem ungefähren Alter des Systems, aber ohne Kennung, damit Fedora weiß, wie viele Systeme es nutzen.
  • Firefox: Telemetrie, Studien, gesponserte Inhalte und Werbemessung sind aus. uBlock Origin blockiert Werbung und Tracker, und Websites öffnen sich wann immer möglich über HTTPS.
  • Das Werkzeug Web-Apps: Beim ersten Öffnen lädt es das Logo jeder angebotenen Website von dieser Website selbst und speichert es auf dem Computer. Eine Website, die Sie selbst hinzufügen, wird ebenso kontaktiert.
  • Kinderkonten mit eingeschaltetem Webfilter (Jugendschutz): Um Websites zu sperren, werden die Namen der Websites, die sie öffnen, an den Familienfilter von CleanBrowsing statt an den üblichen DNS-Server gesendet.
  • Tailscale ist installiert, für sudo tailscale up: Sein Dienst läuft, tritt aber keinem Netzwerk bei, bevor Sie sich anmelden.

Um die Fedora-Zählung zu stoppen, oder den Tailscale-Dienst, wenn Sie ihn nicht nutzen:

sudo systemctl mask --now rpm-ostree-countme.timer
sudo systemctl disable --now tailscaled.service

Die Firewall (firewalld) ist aktiv; die App Firewall ändert ihre Einstellungen. Flatseal zeigt und ändert, worauf jede Flatpak-App zugreifen darf (Dateien, Geräte, Netzwerk).

Downloads prüfen

Die Prüfsumme jeder Live-ISO ist mit dem Projektschlüssel cosign.pub signiert. Laden Sie die ISO, ihre Datei .sha256 und ihre Signatur .sha256.sigstore.json in denselben Ordner herunter und prüfen Sie sie mit cosign (für die NVIDIA-ISO die Namen celenn-nvidia-live-amd64 verwenden):

cosign verify-blob --key cosign.pub \
  --bundle celenn-live-amd64.iso.sha256.sigstore.json \
  celenn-live-amd64.iso.sha256
sha256sum -c celenn-live-amd64.iso.sha256

Auch die System-Images sind signiert, und installierte Systeme lehnen unsignierte Updates ab. Jedes Image enthält außerdem eine signierte Liste seiner Pakete (eine SPDX-SBOM):

cosign verify --key cosign.pub ghcr.io/celenn-os/celenn:stable
cosign verify-attestation --key cosign.pub --type spdxjson \
  --insecure-ignore-tlog=true ghcr.io/celenn-os/celenn:stable

Hilfe finden

Etwas funktioniert nicht? Die Seite Fehlerbehebung behandelt die häufigsten Probleme.

Eine Frage, oder etwas ist unklar? Fragen Sie in den Discussions.

Einen Fehler gefunden? Führen Sie dies in einem Terminal auf dem betroffenen Computer aus: Es sammelt die Systemdaten (keine persönlichen Daten) und öffnet einen Fehlerbericht, in dem sie schon eingetragen sind. Beschreiben Sie dann, was Sie getan haben und was passiert ist.

ujust report-bug
