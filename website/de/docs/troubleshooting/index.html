Fehlerbehebung

Etwas ist schiefgegangen? Die meisten Probleme mit cosmic-blue lassen sich rückgängig machen: Die vorherige Systemversion bleibt installiert, und Ihre COSMIC-Einstellungen lassen sich auf die Standardwerte zurücksetzen. Die Befehle gehören in ein Terminal. Siehe auch die Dokumentation.

Der Computer startet nicht Ein Update hat etwas kaputt gemacht Der Desktop startet nicht Aussehen und Einstellungen Eine App funktioniert nicht Updates werden nicht installiert NVIDIA-Treiber Ein Problem melden

Der Computer startet nach einem Update nicht

  1. Schalten Sie den Computer ein und drücken Sie mehrmals Esc (oder halten Sie Umschalt gedrückt), bis das Startmenü erscheint.
  2. Wählen Sie den zweiten Eintrag, markiert mit ostree:1: Das ist die Version, die Sie vor dem Update hatten.
  3. Behalten Sie diese Version, sobald Sie auf dem Desktop sind, auch für die nächsten Starts:
sudo bootc rollback

Folgen Sie dann dem nächsten Abschnitt, damit die kaputte Version nicht zurückkommt.

Ein Update hat etwas kaputt gemacht

Kehren Sie zur Version zurück, die Sie vorher hatten. Sie bleibt bis zum nächsten Update installiert, das funktioniert also auch offline:

sudo bootc rollback    # beim nächsten Start die vorherige Version nutzen
sudo systemctl reboot

Die automatischen Updates würden die kaputte Version wieder installieren. Pausieren Sie sie, melden Sie das Problem und schalten Sie sie wieder ein, sobald eine Korrektur erschienen ist:

ujust toggle-updates disable   # automatische Updates pausieren
ujust toggle-updates enable    # später wieder einschalten

Weiter zurückgehen

Jeder Build hat seine eigene Version, etwa 44.20261110: sudo bootc status zeigt Ihre an, und die Release-Seite listet die wöchentlichen auf. Sie können eine davon installieren und später zu den normalen Updates zurückkehren. Auf dem NVIDIA-Image schreiben Sie cosmic-blue-nvidia statt cosmic-blue.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:44.20261110   # bei dieser Version bleiben
sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue:stable        # zurück zu den wöchentlichen Updates

Der Desktop startet nicht

Schwarzer Bildschirm, oder zurück zum Anmeldebildschirm nach Eingabe des Passworts? Ihre COSMIC-Einstellungen könnten die Ursache sein.

  1. Drücken Sie Strg+Alt+F3, um eine Textkonsole zu öffnen, und melden Sie sich mit Benutzername und Passwort an.
  2. Setzen Sie die COSMIC-Einstellungen zurück (Ihre Dateien und Apps bleiben unberührt) und starten Sie neu:
ujust reset-cosmic-config
sudo systemctl reboot

Wenn es nach einem Update anfing, kehren Sie stattdessen von derselben Konsole aus zur vorherigen Version zurück.

Aussehen und Einstellungen

Das cosmic-blue-Aussehen ist weg, oder eine Leiste, das Dock oder ein Tastenkürzel verhält sich seltsam? Setzen Sie nur das Aussehen oder alle COSMIC-Einstellungen zurück. Melden Sie sich danach ab und wieder an.

ujust reset-cosmic-theme
Farben, dunkles Theme, Icons, Schriften und Hintergrundbild wiederherstellen. Leiste, Dock, Tastatur und Tastenkürzel bleiben erhalten.
ujust reset-cosmic-config
Alle COSMIC-Einstellungen zurücksetzen, aber Tastaturbelegung und Uhrzeitformat behalten. Die alten Einstellungen werden in einen Ordner ~/.config/cosmic.backup- verschoben, und der Befehl zeigt, wie man sie zurückholt.

Eine App funktioniert nicht

Apps aus dem COSMIC Store sind Flatpaks. Aktualisieren Sie sie und reparieren Sie zuerst die installierten Dateien:

flatpak update
sudo flatpak repair

Immer noch kaputt? Starten Sie die App mit frischen Einstellungen. Suchen Sie ihre ID und verschieben Sie ihre Daten zur Seite (Ordner zurücklegen, um es rückgängig zu machen):

flatpak list --app
mv ~/.var/app/org.example.App ~/.var/app/org.example.App.old

Eine App aus FlatPark macht Probleme? ujust toggle-flatpark off deinstalliert seine Apps und schaltet FlatPark ab.

Updates werden nicht installiert

Starten Sie das Update von Hand, um den Fehler zu sehen, und prüfen Sie, ob die automatischen Updates eingeschaltet sind:

ujust update
ujust toggle-updates

Festplatte voll? In cosmic-blue Werkzeuge, Pflege, entfernt Aufräumen, was nichts mehr braucht: Flatpak-Laufzeiten, ungenutzte Container-Images, alte Homebrew-Downloads. Ihre Dateien, Container und deren Volumes bleiben. Im Terminal: ujust clean-system.

NVIDIA-Treiber

Auf dem NVIDIA-Image mit eingeschaltetem Secure Boot wird der Treiber erst geladen, wenn sein Schlüssel registriert ist. Führen Sie den Befehl unten aus und starten Sie neu: Ein blauer Bildschirm fragt nach Enroll MOK, mit dem Passwort cosmicblue (auf QWERTY-Belegung eingegeben).

ujust enroll-secure-boot-key

Das Standard-Image auf einem Computer mit NVIDIA-Karte installiert? Wechseln Sie zum NVIDIA-Image:

sudo bootc switch --enforce-container-sigpolicy ghcr.io/cosmic-blue-os/cosmic-blue-nvidia:stable

Ein Problem melden

Führen Sie den ersten Befehl unten auf dem betroffenen Computer aus: Er sammelt die Systemdaten (keine persönlichen Daten) und öffnet einen Fehlerbericht, in dem sie schon eingetragen sind. Beschreiben Sie, was Sie getan haben und was passiert ist. Trat das Problem beim vorherigen Start auf, fügen Sie die protokollierten Fehler hinzu (zweiter Befehl). Fragen gehören in die Discussions.

ujust report-bug
sudo journalctl -b -1 -p err --no-pager
